# Riddle Game: Android reconstruction

Java Android app based on the February 2020 report: welcome screen, five riddles, spoken hints using Android built-in TextToSpeech, photo capture, progress, and win screen. The old project used IBM Watson Visual Recognition and Text-to-Speech; **this prototype does not integrate IBM Watson**. Photo correctness is marked manually for demonstration. No model, API credentials, trained datasets, or original source code were recovered.

Open this directory as a project in Android Studio with JDK 17 and a compatible Android Gradle Plugin environment; sync Gradle, then run on an Android device or emulator. The Gradle wrapper is not bundled; an installed Gradle/Android Studio distribution is needed.
